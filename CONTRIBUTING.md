# Contributing to a/webgames

Share a Post or Artifact from the Wall, https://abstracts.co/a/webgames/wall, or open a pull request here. Maintainers (starting with @bubbawrap) accept or close it.

Use the Artifact cube for a bundle in `artifacts/<id>/`; check its title and cover, then Post. Text, photos, links and notes stay Discussions. Configuration and skills use native repository writer tools.
